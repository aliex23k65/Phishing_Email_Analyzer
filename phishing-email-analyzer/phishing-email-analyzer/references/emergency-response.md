# FS.COM 钓鱼邮件应急响应手册

本手册面向销售同事，提供"已经中招"后的分场景应急处理步骤。
语言尽量通俗，每一步都要具体可执行。

---

## 场景一：输入了 Google / Microsoft 365 账号密码

### 紧急程度：🔴 极高（黄金处理时间：30 分钟内）

攻击者拿到你的密码后，通常会在几分钟内登录你的邮箱，设置转发规则来持续监控你的邮件，
甚至冒充你给客户发邮件。所以速度是关键。

### 立即执行（按顺序）：

1. **改密码**
   - Google：https://myaccount.google.com/security → 密码
   - Microsoft 365：https://mysignins.microsoft.com → 更改密码
   - 新密码不要跟旧密码有任何关联

2. **开启两步验证**（如果还没开）
   - Google：https://myaccount.google.com/signinoptions/two-step-verification
   - Microsoft：https://mysignins.microsoft.com → 安全信息 → 添加方法

3. **检查邮箱转发规则**（攻击者最常做的事）
   - Gmail：设置 → 转发和 POP/IMAP → 检查是否有你没设置过的转发地址
   - Gmail：设置 → 过滤器和屏蔽的地址 → 检查是否有陌生的过滤规则
   - Outlook：设置 → 邮件 → 转发 → 检查是否被开启了转发
   - Outlook：设置 → 邮件 → 规则 → 检查是否有陌生规则

4. **检查最近的登录活动**
   - Google：https://myaccount.google.com/notifications → 查看是否有陌生设备/地点的登录
   - Microsoft：https://mysignins.microsoft.com → 查看登录活动

5. **检查第三方应用授权**
   - Google：https://myaccount.google.com/permissions → 撤销不认识的应用
   - Microsoft：https://myapps.microsoft.com → 检查已授权的应用

6. **通知信息安全部**
   - 发邮件至 info-security@feisu.com
   - 说明：什么时候、在哪个页面输入了密码、用的哪个账号
   - 信安部会帮你做进一步的安全检查和账号加固

## 场景二：点击了可疑链接（但没有输入密码）

### 紧急程度：🟡 中等

仅仅点击链接，如果没有输入任何信息，风险相对可控。
但某些链接可能会自动下载恶意文件或利用浏览器漏洞。

### 立即执行：

1. **关闭该网页**，不要在页面上做任何操作
2. **检查浏览器下载记录**，看是否有自动下载的文件，如果有，不要打开，直接删除
3. **清除浏览器缓存和 Cookie**
   - Chrome：设置 → 隐私和安全 → 清除浏览数据 → 选择"Cookie"和"缓存"
4. **观察电脑是否有异常**：
   - 是否突然变慢
   - 是否弹出奇怪的窗口
   - 杀毒软件是否有告警
5. 如果一切正常，基本没事。但如果后续发现异常，联系 info-security@feisu.com

## 场景三：打开了可疑附件

### 紧急程度：🔴 高

### 根据附件类型分别处理：

#### 打开了 .html/.htm 附件

- 如果只是看到了页面但没有输入密码 → 参考场景二
- 如果输入了密码 → 参考场景一

#### 打开了 .exe / .scr / .js / .vbs 等可执行文件

- 立即断开网络（拔网线或关 WiFi）
- 不要关机（保留现场供信安部分析）
- 立即联系 info-security@feisu.com
- 信安部可能需要远程检查你的电脑

#### 打开了 Office 文档并启用了宏

- 立即关闭文档
- 断开网络
- 联系 info-security@feisu.com
- 说明：打开了什么文件、是否点击了"启用内容/启用宏"

#### 打开了 .zip/.rar 并解压了文件

- 如果解压出来的是 .html → 参考上面 .html 的处理
- 如果解压出来的是 .exe 等可执行文件 → 参考上面可执行文件的处理
- 如果只是解压了但没有打开里面的文件 → 删除解压出来的文件和压缩包即可

## 场景四：已经按钓鱼邮件的要求转了钱

### 紧急程度：🔴🔴 最高（每一分钟都在增加损失）

### 立即执行（按顺序，越快越好）：

1. **立即联系财务部**，告知转账详情，请求联系银行拦截
2. **联系银行**，申请冻结/撤回转账（跨境转账通常有 24-72 小时的处理窗口）
3. **联系 info-security@feisu.com**，提供：
   - 钓鱼邮件原文
   - 转账金额、时间、收款账号信息
   - 你与"客户"的沟通记录
4. **保留所有证据**，不要删除任何邮件或聊天记录
5. 信安部会协调后续的报案和追款流程

## 场景五：授权了可疑的第三方应用（OAuth）

### 紧急程度：🔴 高

OAuth 授权比密码泄露更隐蔽——即使你改了密码，攻击者仍然可以通过已授权的应用
访问你的邮件和文件。

### 立即执行：

1. **撤销授权**
   - Google：https://myaccount.google.com/permissions → 找到可疑应用 → 移除访问权限
   - Microsoft：https://myapps.microsoft.com → 找到可疑应用 → 撤销权限
2. **检查邮箱转发规则**（同场景一的第 3 步）
3. **检查最近的登录和操作记录**
4. **联系 info-security@feisu.com**，说明授权了什么应用

---

## 通用原则

- **速度第一**：发现中招后，先处理再汇报，不要等
- **保留证据**：不要删除钓鱼邮件、不要清空回收站，信安部需要这些做分析
- **不要自责**：钓鱼攻击是专业犯罪团伙设计的，中招不丢人，及时处理最重要
- **主动告知**：如果你的邮箱可能被控制了，主动告知最近联系过的客户，
  提醒他们注意来自你邮箱的异常邮件（特别是涉及付款的）

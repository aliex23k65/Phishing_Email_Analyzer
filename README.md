# Phishing Email Analyzer

一个基于 AI Agent 的钓鱼邮件智能分析 Skill，以红队视角帮助企业员工识别和应对社会工程学攻击。

## 项目背景

在企业安全运营实践中，钓鱼邮件是最主要的初始攻击向量之一。传统的邮件网关侧重于特征匹配，对新型社工攻击（如 BEC、OAuth 劫持、定向鱼叉攻击）检出率有限。本项目将安全分析师的研判经验沉淀为 AI Skill，实现：

- 多维度威胁分析（身份伪装、品牌仿冒、话术识别、业务逻辑悖论）
- 结构化输出审计报告，降低安全团队分析负担
- 面向非安全人员的通俗化解读，缩短应急响应时间

## 核心能力

- **攻击链分析**：从发件身份校验、内容话术、附件/链接载荷、业务逻辑四个维度构建完整分析链
- **三色预警分级**：基于风险评分（0-100）输出 🟢 安全 / 🟡 疑似 / 🔴 高危分级，匹配差异化处置建议
- **附件源码审计**：解析 HTML/JS 钓鱼页面源码，检测凭据外传逻辑、反分析对抗代码、定向攻击特征
- **URL 信誉查询**：集成域名信誉查询，识别短链跳转和多级重定向
- **业务上下文感知**：理解企业业务流程，识别支付重定向、收款变更等高级 BEC 攻击

## 威胁覆盖

| 攻击类型                      | 检测能力             |
| ----------------------------- | -------------------- |
| 仿冒登录页（Google/M365/SSO） | ✅ 源码级分析        |
| BEC / CEO 欺诈                | ✅ 业务逻辑校验      |
| 恶意附件（HTML/PDF/Office宏） | ✅ 文件类型+行为分析 |
| OAuth 授权劫持                | ✅ 权限请求识别      |
| 支付重定向                    | ✅ 交易流程异常检测  |
| 鱼叉式定向攻击                | ✅ 个性化特征识别    |
| 克隆钓鱼                      | ✅ 上下文对比分析    |

## 技术架构

```
用户输入（邮件原文/截图/链接/附件源码）
    ↓
┌─────────────────────────────────┐
│   预处理层                       │
│   - 输入类型识别                  │
│   - 信息完整性评估                │
│   - 脱敏提醒                     │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│   分析引擎（Chain of Thought）   │
│   1. 身份伪装深度校验             │
│   2. 品牌劫持与登录陷阱检测       │
│   3. 内容话术与心理操控分析       │
│   4. 附件/链接风险评估            │
│   5. 业务逻辑悖论审计            │
│   6. 攻击类型分类                │
└─────────────────────────────────┘
    ↓
┌─────────────────────────────────┐
│   输出层                         │
│   - 风险评分 & 三色分级          │
│   - 结构化审计报告               │
│   - 可操作的处置建议             │
└─────────────────────────────────┘
```

## 安装与使用

1. 将本目录放入 Kiro 的 skills 目录
2. 在对话中提到钓鱼邮件相关话题时自动激活
3. 支持的输入方式：邮件原文、邮件头信息、可疑链接、附件源码、截图

## 设计理念

- **业务优先**：安全审计不以牺牲业务为代价，对疑似邮件提供安全验证路径而非直接封杀
- **知识沉淀**：将安全分析师的经验以结构化 Prompt 工程固化，可复用、可迭代
- **场景驱动**：基于真实企业攻防案例构建模式库，非理论堆砌
